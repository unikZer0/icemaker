ชื่ออุปกรณ์สถานที่ติดตั้งการเชื่อมต่อสถานะข้อมูลล่าสุด (กรุงเทพฯ)แดชบอร์ด

เหตุการณ์จากอุปกรณ์

ตรวจสอบทุก 5 วินาที · ข้อมูลขาดหายเกิน 90 วินาทีถือว่าออฟไลน์

เวลา (กรุงเทพฯ)อุปกรณ์เหตุการณ์สถานะLINEจัดการ

ตั้งค่าการแจ้งเตือนผ่าน LINE

ใช้ LINE Official Account และ Messaging API เพื่อส่งข้อความถึงผู้ใช้หรือกลุ่มที่กำหนด

เหตุการณ์ที่ต้องการส่ง

ปุ่มทดสอบจะส่งข้อความจริงไปยังผู้รับที่บันทึกไว้ กรุณาบันทึกการเปลี่ยนแปลงก่อนทดสอบ

เริ่มต้นใช้งาน

เชื่อมต่อ LINE ของคุณ

  1. เตรียม LINE Official Account และเปิดใช้งาน Messaging API
  2. นำ Channel access token จาก LINE Developers มากรอก
  3. เพิ่มบัญชีเป็นเพื่อน หรือเชิญเข้ากลุ่ม แล้วระบุรหัสผู้รับ
  4. เลือกเหตุการณ์ บันทึก และกดส่งข้อความทดสอบ
คู่มือ LINE Messaging API ↗

ข้อความจะส่งเมื่อเกิดเหตุการณ์ โดยไม่ส่งซ้ำทุกครั้งที่มีข้อมูลใหม่ การทดสอบและการส่งจริงขึ้นอยู่กับสิทธิ์และโควตาของบัญชี LINE
